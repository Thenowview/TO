Security posture
◎
Local-only inference
Only 127.0.0.1 runtime addresses are permitted.
⌑
Bearer-token API
Token generated locally, never sent to a cloud service by this engine.
▤
Restricted files
Operations limited to your TheOrg workspace and explicit UI confirmation.
⚠
Mobile LAN notice
Direct LAN HTTP is unencrypted. Prefer running locally on the phone or a private authenticated network; never port-forward.
Recent audit events
Implemented vs planned
Implemented: offline model adapters, SQLite tasks, 12 role prompts, local files/memory, approved Code Studio edits, failed-test-informed repair proposals, read-only code search, allowlisted Python unit tests, local Git verification and commits. Not implemented: operating-system-wide sandbox for the engine itself, arbitrary shell, clone/push/PRs, Android-native inference, full browser/desktop automation, parallel autonomous agent scheduler or cloud sync.
