The Windows controller is installed and registered. No additional browser or application download is required. Chrome requires one manual extension approval before the dashboard can run.

One-time Chrome setup

  1. In the Google Chrome window opened by the installer, go to chrome://extensions and enable Developer mode (top right).
  2. Click Load unpacked and choose the exact folder shown below. Do not select its parent folder.
  3. Verify the extension appears as TheOrg — Supervisor Workspace. Click its icon, or use the desktop shortcut TheOrg - Chrome.
  4. In the Supervisor click Check connection. Expected: Local controller connected.
